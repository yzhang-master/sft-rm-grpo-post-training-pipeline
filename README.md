# sft-rm-grpo-post-training-pipeline

A local, CPU-executable SFT → reward model → PRM → GRPO pipeline with verified math/tool rewards, validated artifacts, and safe stage resume. The included model and datasets are tiny systems-test fixtures, not a 3B training run.

See `configs/tiny_cpu.json` for the single pipeline configuration and `scripts/run_pipeline.py` for the entry point.
